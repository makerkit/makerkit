Initial release: translation tools for coding agents (`translations_list`, `translations_update`, `translations_stats`, `translations_add_namespace`, `translations_add_locale`, `translations_remove_namespace`, `translations_remove_locale`) for projects that keep JSON files as `<locale>/<namespace>.json`, extracted from the Makerkit kits' MCP servers. The messages directory, the base locale and the JSON indentation are settings. Written files now end with a newline, and returned paths always use forward slashes.
